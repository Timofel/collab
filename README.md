# Простой набор нейронных сетей для демонстрации работы

## 1 !symbols_ns
Гибридная нейронная сеть по распознаванию букв

- имеет ошибки при работе, неверно вычисляет буквы

## 2 simple_version
Простая нейронная сеть определяющая снимок дефектный или нет
при запуске `app.py` запускает простой сервера на локальной машине по адресу `http://127.0.0.1:5000/`

## 3 no_simple_version
Работает на основе Yolo8n определяет точные дефекты
